cost：
阶梯电价计费：为了提倡居民节约用电，某省电力公司执行“阶梯电价”，安装一户一表的居民用户电价分三个阶梯：
月度用电量为150度（含150度）以内的，每度电0.6元；
400度（含400度），超出150度部分每度电0.8元；401度以上，每度电1.0元。
给出一个家庭一月用电量，请计算出应缴的电费（四舍五入，保留小数点后两位小数）。

carfee：
根据某城市普通出租车收费标准编写程序进行车费计算。具体标准如下：
起步里程为3公里，起步费10元；
3公里以上10公里内（包含)的部分，每公里2元；
超过10公里的部分加收50%的回空补贴费，即每公里3元;
营运过程中，因路阻及乘客要求临时停车的，按每5分钟2元计收(不足5分钟则不收费)。
输入输出格式:
在第一行中给出输入行驶里程(单位为公里，精确到小数点后1位)与等待时间(整数，单位为分钟)，其间以空格分隔。
在第二行中输出乘客应支付的车费(单位为元)，结果四舍五入，保留到分。

character：
从键盘上输入一个字符，判断并输出是控制符、数字字符、大写字母、小写字母或是其他字符。
从ASCII码表可知，ASCII码值小于32的为控制字符，在'0'和'9'之间的为数字字符，在'a'和'z'之间的为小写字母，在'A'和'Z'之间的为大写字母。其余均为其他字符。
输入输出用例：（其中第一行是输入，第二行是输出）
输入样例1：
(键盘上敲Tab键)
This is a control character
输入样例2：
A
This is a capital letter
输入样例3：
a
This is a small letter
输入样例4：
5
This is a digit
输入样例5：
*
This is an other character

num：
从键盘输入一个不多于4位的正整数num，请使用if多分支语句编程实现以下功能：
(1) 求出它是几位数；
(2)按千、百、十、个位顺序输出每一位数字。
输入输出用例：（其中第一行是输入，第二行是输出）
输入输出样例1：
1234
整数1234是4位数，千位：1,百位：2,十位：3,个位：4
输入输出样例2：
123
整数123是3位数，百位：1,十位：2,个位：3
输入输出样例3：
12
整数12是2位数，十位：1,个位：2
输入输出样例4：
1
整数1是1位数，个位：1
