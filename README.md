BMR:
男性基础代谢率计算公式：BMR=88.362+ (13.397×体重kg)+ (4.799×身高cm)- (5.677×年龄）。 
女性基础代谢率计算公式：BMR=447.593+ (9.247×体重kg)+ (3.098×身高cm)- (4.330×年龄)。 
例如，一位30岁，身高180cm，体重75kg的男性，其基础代谢率为：88.362+ (13.397×75)+ (4.799×180)- (5.677×30)=1786.65千卡/天。一位30岁，身高165cm，体重60kg的女性，其基础代谢率为：447.593+ (9.247×60)+ (3.098×165)- (4.330×30)=1383.68千卡/天。

参考河南五险一金缴纳比例，设定以下计算方式：
1. 养老保险  个人缴纳比例：职工工资基数的8%
2. 医疗保险  个人缴纳比例：职工工资基数的2%
3. 工伤保险  个人缴纳比例：0%（由单位全额承担）
4. 生育保险 个人缴纳比例：0%（由单位全额承担）
5. 失业保险 个人缴纳比例：职工工资基数的1%
6. 住房公积金 个人缴纳比例：5%-12%（本例按5%算）

不超过3000元：税率为3%，速算扣除数为0
超过3000元至12000元：税率为10%，速算扣除数为210
超过12000元至25000元：税率为20%，速算扣除数为1410
超过25000元至35000元：税率为25%，速算扣除数为2660
超过35000元至55000元：税率为30%，速算扣除数为4410
超过55000元至80000元：税率为35%，速算扣除数为7160
超过80000元：税率为45%，速算扣除数为15160

应纳税所得额 = 税前工资收入金额 - 五险一金 - 起征点5000元
应纳税所得额<=0则不扣税。

输出数据精确到分，即格式为保留小数点后2位。
